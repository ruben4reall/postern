メールボックスの扉は、あなたの手に。

Mac 上で、AI アプリにProton Mail を任せられます。Touch ID で承認するまで、何も送信されず、何も削除されません。

Mac 版をダウンロード
brew install --cask ruben4reall/tap/postern

無料のオープンソース。スイスのヴァレー州で開発。macOS 26 以降と Proton Mail Bridge で動作します。

リクエストがメールボックスに届くまで。

AI アプリが Bridge やパスワード、設定に触れることはありません。アプリがやり取りするのは何も持たない中継役で、判断するのは Postern とあなたです。

  1. アプリが依頼します。 Claude Code が、あなたがオンにしたツールの 1 つ reply_to_message を呼び出します。
  2. 中継役が運びます。 postern-mcp が XPC で Postern に渡します。秘密情報は持たず、何も判断しません。
  3. Postern が確認し、あなたが承認します。 スイッチ、上限、受信者が確認され、パネルにメールが表示されます。Touch ID で承認します。
  4. Bridge が送信します。 承認したバイト列そのものが、TLS で、初期設定時にピン留めした証明書の Bridge に届きます。

何を許すかは、あなたがスイッチで決める。

Postern には、5 つのレベルに分かれた 27 のツールがあります。スイッチはすべてオフから始まります。オフのツールは拒否されるのではなく、存在しません。アプリからは見えないので、呼び出すこともできません。

ツールをオンにするには Touch ID が必要です。オフにするのはすぐで、接続中のアプリにもすぐに反映されます。「一時停止」ですべてが止まり、画面がロックされたときに Postern を自動で一時停止させることもできます。

スイッチを試してみてください。Postern ではツールごとにスイッチがありますが、ここではレベル単位で切り替わります。

  • 読み取り隠しテキストを取り除いたメールを検索し、読みます。
  • 整理既読、スター、移動、ラベル。ゴミ箱や迷惑メールには移しません。
  • 下書き下書きを作成します。何も送信されません。
  • 送信すべてのメールがパネルで Touch ID を待ちます。
  • 削除削除のたびにパネルで一覧を表示し、Touch ID で承認します。

承認時SHA-256 9d65 8e71 5dcb 02af 6e14…

送信時SHA-256 9d65 8e71 5dcb 02af 6e14…同じバイト列

送信されるものを、そのまま確認できます。

メール全体
差出人、すべての受信者、件名、本文全体と引用部分、そしてすべての添付ファイルとそのサイズ、SHA-256 フィンガープリント。
受信者の出どころ
初めての相手、差出人とは別のアドレスに届いてしまう返信、アプリが読んだメールの中で見つけたアドレス。パネルはそれを明示し、特に重要なものは赤で示します。
バイト列に結びついた承認
承認の対象は、送信されるすべてのバイトの SHA-256 です。送信するコードはそれ以外を受け付けないため、あなたが読んだものと送信されるものの間で何かが変わることはありません。
そして Touch ID
プログラムが代わりに入力することはできません。メールを下書きとして残すことも、アプリへのメモを添えて拒否することもできます。2 分間そのままにしたパネルは、拒否として扱われます。

見知らぬ人が書いたメールは、データとして読まれます。

メッセージには、あなたには見えないのにモデルには見えるテキストを隠すことができます。Postern はアプリが何かを読む前にそれを取り除き、残った内容を、送信者には偽造できないマーカーで囲みます。

本当の送信者

各メッセージには、配信時に Proton が記録した内容にもとづく判定が付きます。内部、検証済み、未検証、失敗のいずれかです。信頼できるように見せかけるため送信者がメッセージ内に書き込んだ結果は見抜かれます。

リンクはありのままに

すべてのリンクは実際のリンク先とともに一覧にされ、表示テキストが別のサイトを示している場合や、ドメインに複数の文字体系が混在している場合は警告されます。

隔離されたリーダーで添付ファイルを読む

PDF、スキャン、写真は、ネットワークもキーチェーンもファイルも使えないサンドボックス化されたプロセスで読み取られます。スキャンの文字認識は Mac 上の Vision が行い、何もアップロードされません。

「添付」とあれば、必ず添付。

本文にファイルを添付すると書いてあるのにファイルが付いていないメールは、保存や送信の前に止められます。アプリには理由が伝えられ、ファイルを追加できます。

11 の言語の語句を、件名とアプリが書いた本文の中から読み取ります。引用された元のメールは対象外です。ファイルを添付するつもりがない場合はアプリがそう伝え、パネルにはオレンジ色で表示されます。

ファイルを添付する3 つの方法

  1. 送信用フォルダからattachments

    ~/Downloads/Postern/Outbox またはその中のフォルダに置いたファイル。Mac 上のそれ以外のファイルは添付できず、リンクもたどりません。

  2. アプリが作成inline_attachments

    チャットで作った CSV など、アプリ自身が作成したファイル。テキストまたは base64 で渡され、最大 10 MB です。

  3. 読んだメールからemail_attachments

    請求書を先に保存しなくても、そのまま税理士に転送できます。アプリはメールと添付ファイルの番号を指定するだけです。

1 通あたり最大 20 ファイル、20 MB まで。3 つの方法は自由に組み合わせられます。応答には毎回、送信されたファイルの名前とサイズが含まれます。

保存された下書きはすべて確認されます。 Postern は、Bridge が保持したファイルの数を読み戻します。1 つでも欠けていれば、完成しているように見えて実は不完全な下書きを残すのではなく、その下書きを削除してアプリに知らせます。

最大 5,000 通。パネル 1 枚、Touch ID 1 回。

アプリが CSV または JSON ファイルから、相手ごとに {{values}} を差し込んだ下書きを作成します。1 枚のパネルですべてを確認したら、あとは送信ペースを調整するキューが、上限の範囲内で送信します。

ペースを守る
20 通までは 2 秒間隔、それを超えると 30 秒間隔で送信するため、大量の一括送信でも Proton に一度に押し寄せることはありません。start_at を使えば、最初の 1 通を最大 30 日間待たせられます。
上限の範囲内で
初期値は 1 時間に 10 通、1 日に 30 通です。上限に達すると、一括送信は失敗せずに枠が空くのを待ちます。Touch ID で最大 1 時間に 300 通、1 日に 1,000 通まで引き上げれば、そのぶん速く送信されます。
Bridge が止まっても保留
Bridge が動いていない場合や待機を求められた場合、一括送信は保留され、30 秒後、2 分後、その後は 10 分ごとに再試行します。
二重送信なし
ある一括送信が保留中または送信済みの下書きを、別の一括送信が取ることはできません。タイムアウト後にアプリが再び呼び出しても、2 枚目のパネルは開きません。Bridge が受け取る途中で接続が切れたメールが再送信されることもありません。
再起動しても失われない
承認された一括送信は、進行に合わせて、Postern のキーチェーンにある鍵で暗号化してディスクに保存されます。Mac や Postern を再起動した後は、あなたが Touch ID で「再開」を選ぶまで待機します。
承認したものだけ
各メールはそれぞれのダイジェストを保持します。承認後に Proton で変更した下書きは送信されず、下書きを削除すればそのメールは保留され、「停止」を選べば残りは下書きのまま残ります。

まだ返信がない相手

awaiting_reply は、メールを送ったのに返信がない相手を、待ち時間が長い順に一覧にします。会話内の返信はもちろん、同じアドレスや同じ会社のドメインから後で届いたメールも返信として数えます。

  • Lumen Labs12 日

ワンクリック

Claude Code、Claude Desktop、Codex（ChatGPT の Mac アプリもこの接続を共有します）、Cursor、Copilot を使う VS Code、Windsurf、Gemini CLI、Kiro、Cline なら、Postern の「アプリ」画面で「接続」をクリックするだけです。Postern はそのアプリの設定にエントリを 1 つ書き込みます。中身はヘルパーのパスだけで、パスワードは決して含みません。

その他のアプリは貼り付けるだけ

Zed、OpenCode、Goose、Continue などその他のアプリには、Postern がそのアプリ独自の形式で、貼り付けるためのエントリを用意します。stdio 経由で MCP サーバーを起動できるクライアントなら、どれでも同じヘルパーを起動できます。

{
  "mcpServers": {
    "proton-mail-postern": {
      "command": "/Applications/Postern.app/Contents/Helpers/postern-mcp"
    }
  }
}

リスクごとに、それに応える鍵を。

Postern は 1 つのルールにもとづいて作られています。アプリの手が届くものでは、どの鍵も開けられない。アプリが編集できる設定も、埋められる引数も、書き換えられるファイルも、呼び出せるローカルポートも、鍵を開けることはできません。

Bridge のパスワード
macOS のキーチェーンにのみ、Postern の署名済みコードだけが読めるグループに保存されます。アプリの設定に入るのはパスだけで、秘密情報は入りません。
権限を増やそうとするアプリ
スイッチの状態は同じキーチェーングループに保存されます。書き込めるのは Postern のウインドウだけで、権限を増やすには Touch ID が必要です。
Bridge になりすますプログラム
Postern は初期設定時に Bridge の証明書をピン留めし、それ以外は拒否します。接続が暗号化される前にパスワードを送ることはありません。
罠を仕掛けたメッセージ
メールは、ネットワークもキーチェーンもファイルも使えない別プロセスでデコードされます。そこでクラッシュしても、1 通のメッセージが読めなくなるだけです。
Postern に話しかける別のプログラム
Postern のプロセス間のすべての接続で、相手側が Postern の開発者によって署名されていることを双方向で確認します。
改ざんされたアップデート
バージョンの一覧とすべてのアップデートは Postern 独自の鍵（EdDSA）で署名されており、この鍵はメンテナの Mac から外に出ません。あなたがクリックしない限り、何もインストールされません。
Mac から離れるとき
画面がロックされたときに Postern を自動で一時停止させることができます。再開には Touch ID が必要です。
ディスク上で待機中の一括送信
Postern のキーチェーングループにある鍵を使い、ChaCha20-Poly1305 で暗号化されます。ほかのプログラムがメールの宛先を読むことはできず、変更されたファイルは開けません。勝手に再開することもありません。

通信先は 2 つ、どちらも明示

Postern が通信するのは Mac 上の Bridge です。それ以外の接続はアップデートの確認だけで、あなたが許可するまではオフです。1 日 1 回、getpostern.vercel.app にある署名済みのバージョン一覧を読み込み、アップデートを GitHub からダウンロードします。それによって伝わるのは IP アドレスと Postern のバージョンだけです。アクセス解析も、テレメトリも、メールのコピーもありません。

アクティビティログには、どのアプリがいつどのツールを呼び出したかが記録され、メールの内容は決して記録されません。各エントリは直前のエントリとチェーンでつながっているため、編集されればわかります。

Postern が防げないこと

  • あなたが承認したメール。承認すれば送信されます。
  • 読み取りをオンにした後にアプリが読む内容。アプリに触れさせたくないメールボックスは非表示にしてください。
  • アプリが読んだ内容をどう扱うか。
  • 管理者権限を持つマルウェアや、画面を操作できるマルウェア。
  • Bridge そのものと、Proton が記録する配信結果。

完全な脅威モデルを読む

1 分で準備完了。

macOS 26 以降と、同じ Mac でサインイン済みの Proton Mail Bridge が必要です。

  1. Bridge を準備する

    Proton Mail Bridge をインストールし、Proton アカウントにサインインします。

  2. Postern をインストールする

    ディスクイメージをダウンロードし、Postern を「アプリケーション」フォルダにドラッグします。Developer ID で署名され、Apple の公証を受けています。SHA-256 はその横に記載されています。

  3. Bridge を信頼して、サインインする

    Postern が Bridge を見つけ、その証明書のフィンガープリントを表示します。Bridge の「Mailbox details」に表示されるユーザー名とパスワードを貼り付けます。このパスワードは Bridge が作成したもので、Proton のパスワードではありません。

  4. アプリを接続する

    Touch ID で読み取りを許可し、使っている AI アプリの横にある「接続」をクリックします。アプリを再起動するか新しいセッションを開いたら、普段の言葉で頼んでみてください。

よくある質問

Postern の料金は？

無料です。Postern は MIT ライセンスのもとで公開されている無料のオープンソースソフトウェアで、コードは GitHub で公開しています。

どの Proton Mail プランで使えますか？

Postern は Proton Mail Bridge を通じてメールボックスにアクセスするため、Bridge を使えるアカウントならどれでも使えます。Proton は、Proton Mail を含む有料プランで Bridge を提供しています。最新の情報は Proton の Bridge のページをご覧ください。

Postern はデータをどこかに送信しますか？

いいえ。Postern が通信するのは Mac 上の Bridge で、メールのコピーは保存しません。それ以外の接続は 1 日 1 回のアップデート確認だけで、それもあなたが許可した場合に限ります。Vercel と GitHub に伝わるのは IP アドレスと Postern のバージョンだけです。アクセス解析もテレメトリもありません。AI アプリが読んだメールをどう扱うかは、そのアプリ次第です。

AI アプリが私の知らないうちにメールを送ることはありますか？

すべてのメールは承認パネルで待機し、あなたが「送信」を選んで Touch ID で認証した後にだけ送信されます。パネルを通さずに済む唯一の方法は、Postern のウインドウであなただけが登録できる「信頼済み受信者」のリストです。送信先を「許可された受信者」のリストに限定することもできます。

メールを削除できますか？

「削除」のツールをオンにした場合に限ります。削除のたびに対象のメッセージがすべてパネルに一覧表示され、Touch ID が必要です。完全消去できるのは、すでにゴミ箱か迷惑メールにあるメッセージだけです。

どの AI アプリで使えますか？

Claude Code、Claude Desktop、Codex、Cursor、Copilot を使う VS Code、Windsurf、Gemini CLI、Kiro、Cline はワンクリックで接続できます。stdio 経由でサーバーを起動するその他の MCP クライアントには、Postern がそのアプリの形式で貼り付けるためのエントリを用意します。

一括送信の途中で Bridge が止まったら？

一括送信は保留され、30 秒後、2 分後、その後は 10 分ごとに再試行します。何も失われません。下書きが「下書き」フォルダから消えるのはそのメールが送信されたときだけで、Bridge が受け取る途中で接続が切れたメールを一括送信が再送信することはありません。Mac が再起動した場合は、一括送信が復元され、あなたが Touch ID で再開するのを待ちます。

Postern はどのようにアップデートされますか？

Sparkle を使います。Postern は毎日確認するかどうかを一度だけ尋ね、どちらを選んでも「アップデートを確認」は使えます。バージョンの一覧とすべてのアップデートは Postern 独自の鍵で署名されており、開く前に検証されます。「インストールして再起動」をクリックするまで、何もインストールされません。

Postern は日本語に対応していますか？

Postern のウインドウ、メニュー、承認パネルは、英語、フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語、オランダ語、ポーランド語、日本語、中国語、韓国語に対応しており、Mac の言語設定に従います。AI アプリは、どの言語でもメールを読み書きできます。

Postern は Proton が作っているのですか？

いいえ。Postern は Ruben Catalao による独立したプロジェクトで、Proton がスイスの企業であるように、スイスのヴァレー州で開発されています。Proton AG とは提携しておらず、Proton AG の承認も受けていません。
