邮箱的门，握在你手里。

让 AI 应用在你的 Mac 上处理 Proton Mail 邮件。在你用 Touch ID 批准之前，任何邮件都不会被发送或删除。

下载 Mac 版
brew install --cask ruben4reall/tap/postern

免费且开源。在瑞士瓦莱州开发。需要 macOS 26 或更高版本，以及 Proton Mail Bridge。

请求如何到达你的邮箱。

AI 应用从不接触 Bridge、你的密码或你的设置。它只与一个什么都不持有的中继通信，由 Postern 和你一起做决定。

  1. 应用发出请求。 Claude Code 调用 reply_to_message，这是你开启的工具之一。
  2. 中继负责传递。 postern-mcp 通过 XPC 把请求交给 Postern。它不持有任何机密，也不做任何决定。
  3. Postern 检查，你来批准。 开关、你的限额和收件人都经过检查，然后面板向你展示这封邮件。Touch ID 表示同意。
  4. Bridge 发送邮件。 经你批准的字节原样通过 TLS 发往 Bridge，对应你在设置时固定的证书。

它们能做什么，由你开启。

Postern 提供 27 个工具，分为五个级别。所有开关初始均为关闭。关闭的工具并不是被拒绝，而是根本不存在：应用看不到它，也就无法调用它。

开启工具需要 Touch ID。关闭则立即生效，已连接的应用会马上看到变化。“暂停”会停止一切，Postern 还可以在屏幕锁定时自动暂停。

试试这些开关。在 Postern 中每个工具都有自己的开关，这里则按级别一起切换。

  • 读取搜索和阅读邮件，隐藏文本已清除。
  • 整理标为已读、加星标、移动、加标签。绝不移到回收站或垃圾邮件。
  • 草稿撰写草稿。不会发送任何邮件。
  • 发送每封邮件都在面板上等待 Touch ID。
  • 删除每次删除都在面板上列出，并需要 Touch ID。

批准时SHA-256 9d65 8e71 5dcb 02af 6e14…

发出时SHA-256 9d65 8e71 5dcb 02af 6e14…字节相同

发出的内容，你看得一清二楚。

完整的邮件
发件人、每位收件人、主题、完整正文和引用部分，以及每个附件的大小和 SHA-256 哈希值。
收件人从何而来
首次联系的人、会发往与发件人不同地址的回复，或应用在读过的邮件中找到的地址：面板都会标明，最要紧的用红色显示。
与字节绑定
你的批准涵盖所有发出字节的 SHA-256。负责发送的代码不接受其他任何内容，因此从你读到的到发出去的，中间不会有任何改动。
然后是 Touch ID
程序无法代你完成。你也可以把邮件保留为草稿，或附上给应用的说明后拒绝。面板闲置两分钟即视为拒绝。

陌生人写的邮件，只当作数据来读。

邮件可以藏有你看不到、但模型能看到的文本。Postern 会在应用读取任何内容之前将其移除，并把剩余内容包裹在发件人无法伪造的标记中。

真正的发件人

每封邮件都带有一个判定，依据是 Proton 在投递时记录的结果：内部、已验证、未验证或失败。发件人为显得可信而写进邮件里的结果会被识破。

链接如实呈现

每个链接都会连同其真实目标一起列出；如果链接文字指向另一个网站，或其域名混用了多种文字，就会被标出。

附件在密封的读取器中打开

PDF、扫描件和照片在一个沙盒进程中读取，没有网络、没有钥匙串，也无法访问文件。扫描件由你 Mac 上的 Vision 识别，不会上传任何内容。

说了“附件”，就得有附件。

如果邮件正文说附有文件，却没有带任何文件，它会在保存或发送之前被拦下。应用会得知原因，并可以补上文件。

它能识别十一种语言中的这类词语，检查主题和应用写下的内容，而不检查引用的原文。如果本来就不打算附加文件，应用会说明，面板会以橙色显示。

附加文件的三种方式

  1. 来自发件文件夹attachments

    你放在 ~/Downloads/Postern/Outbox 或其子文件夹中的文件。Mac 上的其他文件都无法附加，也不会跟随任何链接。

  2. 由应用生成inline_attachments

    应用自己生成的文件，例如它在对话中整理出的 CSV，以文本或 base64 形式传入，最大 10 MB。

  3. 来自读过的邮件email_attachments

    无需先保存，就能把发票直接转给你的会计：应用只需指明是哪封邮件、第几个附件。

每封邮件最多 20 个文件、20 MB，三种方式可任意组合。每次回应都会列出已发出的文件及其大小。

每份保存的草稿都会被检查。 Postern 会读回 Bridge 保留了多少个文件。只要少了一个，这份草稿就会被删除并通知应用，而不是留下一份看似完整、实则缺件的草稿。

最多 5,000 封邮件。一个面板，一次 Touch ID。

应用根据 CSV 或 JSON 文件撰写草稿，并为每个人填入 {{values}}。你在一个面板上检查全部邮件，之后由一个按节奏发送的队列在你的限额内发出。

按节奏发送
20 封以内每封间隔两秒，超过则间隔三十秒，因此再长的批量发送也不会一下子涌向 Proton。start_at 可以把第一封推迟最多三十天。
在你的限额之内
默认每小时 10 封、每天 30 封。达到限额时，批量发送会等待名额，而不是失败。用 Touch ID 把限额提高到每小时最多 300 封、每天最多 1,000 封，发送就会加快。
Bridge 停止时暂缓
如果 Bridge 没有运行或要求稍候，批量发送会暂缓，并在 30 秒后、2 分钟后重试，之后每 10 分钟重试一次。
绝不发送两次
已被一个批量发送暂缓或发出的草稿，不能被另一个批量发送拿走；应用在超时后再次调用，也不会出现第二个面板。在 Bridge 接收过程中被中断的邮件，绝不会再次发送。
重启后依然保留
已批准的批量发送会随着进度加密保存在磁盘上，密钥存放在 Postern 的钥匙串中。Mac 或 Postern 重新启动后，它会等你用 Touch ID 选择“继续”。
只发你批准过的
每封邮件都保留自己的摘要。批准后你在 Proton 中改动过的草稿不会发出，删除一份草稿会让它不再发送，而“停止”会把其余邮件保留为草稿。

谁还没有回复

awaiting_reply 会列出你写过信但还没回复的人，等待最久的排在最前。会话中的回复算数，之后来自同一地址或同一公司域名的邮件也算。

先试运行，再按搜索整理

对搜索找到的每封邮件进行归档、移动、加标签或加星标，每次最多 1,000 封，例如一个月前的新闻通讯。dry_run 会先把它们列出来，不做任何更改。

一键连接

在 Postern 的“应用”页面中点按“连接”，即可连接 Claude Code、Claude Desktop、Codex（ChatGPT 的 Mac 应用与它共用连接）、Cursor、搭配 Copilot 的 VS Code、Windsurf、Gemini CLI、Kiro 或 Cline。Postern 会在该应用的设置中写入一个条目：它的辅助程序路径，绝不包含密码。

其他应用，粘贴一段即可

对于其他任何应用，例如 Zed、OpenCode、Goose 或 Continue，Postern 会按照该应用自己的格式给出可粘贴的条目。任何能通过 stdio 启动 MCP 服务器的客户端，都可以启动同一个辅助程序。

{
  "mcpServers": {
    "proton-mail-postern": {
      "command": "/Applications/Postern.app/Contents/Helpers/postern-mcp"
    }
  }
}

每一种风险，都有对应的锁。

Postern 建立在一条规则之上：应用能触及的任何东西，都打不开锁。无论是它能编辑的设置、能填写的参数、能改写的文件，还是能调用的本地端口。

你的 Bridge 密码
只存放在 macOS 钥匙串中，位于只有 Postern 签名代码才能读取的组里。应用设置中只有一个路径，绝无机密。
想要更多权限的应用
开关存放在同一个钥匙串组中。只有 Postern 的窗口可以写入，增加权限需要 Touch ID。
冒充 Bridge 的程序
Postern 在设置时固定 Bridge 的证书，并拒绝其他任何证书。在连接加密之前，它绝不会发送你的密码。
暗藏陷阱的邮件
邮件在一个独立进程中解码，没有网络、没有钥匙串，也无法访问文件。即使在那里崩溃，也只会让一封邮件无法读取，仅此而已。
与 Postern 通信的其他程序
Postern 各进程之间的每个连接，都会双向检查对方是否由 Postern 的开发者签名。
被篡改的更新
版本列表和每个更新都用 Postern 自己的密钥（EdDSA）签名，该密钥从不离开维护者的 Mac。没有你的点按，什么都不会安装。
你离开 Mac 时
Postern 可以在屏幕锁定时自动暂停。恢复时需要 Touch ID。
在磁盘上等待的批量发送
使用 Postern 钥匙串组中的密钥，以 ChaCha20-Poly1305 加密：其他程序无法读取邮件发给谁，被改动的文件也无法打开。它绝不会自行继续。

只有两个目的地，都已写明

Postern 与你 Mac 上的 Bridge 通信。唯一的其他连接是更新检查，在你同意之前保持关闭：它每天一次读取 getpostern.vercel.app 上经过签名的版本列表，并从 GitHub 下载更新。这只会透露你的 IP 地址和 Postern 的版本，别无其他。没有分析统计，没有遥测，也没有你邮件的副本。

活动日志记录哪个应用在何时调用了哪个工具，从不记录你的邮件内容。每条记录都与前一条链接在一起，因此任何修改都会显露出来。

Postern 无法防范的情况

  • 你批准的邮件：它会被发出。
  • 开启读取后应用读到的内容。把不想让它接触的邮箱隐藏起来。
  • 应用如何处理它读到的内容。
  • 拥有管理员权限或能控制你屏幕的恶意软件。
  • Bridge 本身，以及 Proton 记录的投递结果。

阅读完整的威胁模型

一分钟完成设置。

你需要 macOS 26 或更高版本，以及在同一台 Mac 上已登录的 Proton Mail Bridge。

  1. 准备好 Bridge

    安装 Proton Mail Bridge，并登录你的 Proton 账户。

  2. 安装 Postern

    下载磁盘映像，将 Postern 拖到“应用程序”文件夹。它使用 Developer ID 签名并经过 Apple 公证，其 SHA-256 列在旁边。

  3. 信任 Bridge，然后登录

    Postern 会找到 Bridge 并显示其证书指纹。粘贴 Bridge 在 Mailbox details 下显示的用户名和密码：这个密码由 Bridge 生成，不是你的 Proton 密码。

  4. 连接你的应用

    用 Touch ID 允许读取，然后点按你的 AI 应用旁边的“连接”。重新启动该应用或打开新会话，然后用日常语言提出请求。

常见问题

Postern 收费吗？

免费。Postern 是基于 MIT 许可证的免费开源软件，代码托管在 GitHub 上。

哪些 Proton Mail 套餐可以使用？

Postern 通过 Proton Mail Bridge 访问你的邮箱，因此任何能使用 Bridge 的账户都可以。Proton 在包含 Proton Mail 的付费套餐中提供 Bridge，最新详情请参阅 Proton 的 Bridge 页面。

Postern 会把我的数据发送到别处吗？

不会。Postern 与你 Mac 上的 Bridge 通信，不保留你邮件的任何副本。唯一的其他连接是每天一次的更新检查，而且只在你允许时进行：它只会向 Vercel 和 GitHub 透露你的 IP 地址和 Postern 的版本，别无其他。没有分析统计，也没有遥测。AI 应用如何处理它读过的邮件，取决于该应用。

AI 应用能在我不知情时发送邮件吗？

每封邮件都在审批面板上等待，只有在你选择“发送”并通过 Touch ID 后才会发出。唯一绕过面板的方式，是一份只有你能在 Postern 窗口中填写的受信任收件人列表。你还可以把发送限制在一份允许的收件人列表内。

它能删除我的邮件吗？

只有在你开启“删除”工具后才能。每次删除都会在面板上列出所有邮件并需要 Touch ID，而彻底删除只适用于已在回收站或垃圾邮件中的邮件。

哪些 AI 应用可以使用？

Claude Code、Claude Desktop、Codex、Cursor、搭配 Copilot 的 VS Code、Windsurf、Gemini CLI、Kiro 和 Cline 一键即可连接。对于其他通过 stdio 启动服务器的 MCP 客户端，Postern 会按该应用的格式给出可粘贴的条目。

如果 Bridge 在批量发送中途停止怎么办？

批量发送会暂缓，并在 30 秒后、2 分钟后重试，之后每 10 分钟重试一次。不会丢失任何内容：只有在邮件发出后，草稿才会离开“草稿”文件夹；而在 Bridge 接收过程中连接中断的邮件，批量发送绝不会再次发出。如果 Mac 重新启动，批量发送会恢复，并等你用 Touch ID 继续。

Postern 如何更新？

通过 Sparkle。Postern 会询问一次是否每天检查，无论怎么选，“检查更新”都可以使用。版本列表和每个更新都用 Postern 自己的密钥签名，在打开任何内容之前都会验证；在你点按“安装并重新启动”之前，什么都不会安装。

Postern 支持中文吗？

Postern 的窗口、菜单和审批面板支持英语、法语、德语、西班牙语、意大利语、葡萄牙语、荷兰语、波兰语、日语、中文和韩语，并跟随你 Mac 的语言设置。你的 AI 应用可以用任何语言读写邮件。

Postern 是 Proton 开发的吗？

不是。Postern 是 Ruben Catalao 在瑞士瓦莱州开发的独立项目，就像 Proton 也来自瑞士一样。它与 Proton AG 没有关联，也未获其认可。

何时开门，由你决定。
