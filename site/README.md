# Postern's website

A single static page, deployed on Vercel from this folder: `index.html`, `site.css` and `site.js`, no build step.
It uses the system font, Proton Mail's Snow and Carbon colors with purple as the accent, and Postern's own mark.
The product mocks are HTML, CSS and inline SVG. `site.js` plays the explanatory animations, runs the switch demo and
the copy buttons; with Reduce Motion on, everything shows at rest. No tracker, no request to another site.

`appcast.xml` is the signed Sparkle feed: never edit it by hand.
